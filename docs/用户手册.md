# MT5 2PA Agent 用户手册

**版本：v0.4.4 ｜ 适用：EXE 版（Windows）与 Docker 版（Linux/NAS）**

MT5 2PA Agent 是一个 AI 价格行为交易代理：自动拉取 MT5 行情 → 计算 EMA/ATR/SMA 指标与 K 线几何特征 → 两阶段调用大模型（市场诊断 + 交易决策）→ 风控校验后通过 PABridge EA 在 MT5 中自动下单，并提供 Web 控制台实时查看与管理。

---

## 1. 系统组成

```
┌─────────────────────┐   HTTP 轮询(每秒)   ┌──────────────────────┐
│  MT5 终端 (Windows) │ ◄────────────────► │  2PA Agent 代理       │
│  + PABridge EA      │  上报行情/持仓/规格  │  (exe 或 Docker 容器) │
│                     │  领取交易指令        │  + Web 控制台 :8066   │
└─────────────────────┘                    └──────────┬───────────┘
                                                      │ HTTPS
                                               ┌──────▼───────┐
                                               │  LLM 大模型   │
                                               │ (DeepSeek等)  │
                                               └──────────────┘
```

- **MT5 终端 + PABridge EA**：必须运行在 Windows 电脑（MT5 无法装入 Docker），负责行情上报与实际下单。
- **2PA Agent 代理**：核心程序，EXE 版跑在 Windows，Docker 版可跑在 NAS/服务器；提供 Web 控制台（默认端口 8066）。
- **LLM 大模型**：需要一个 OpenAI 兼容接口的 API Key（默认 DeepSeek）。

> EXE 版和 Docker 版功能完全相同，二选一即可。代理与 MT5 可以在同一台电脑，也可以分属两台机器（同一局域网）。

---

## 2. 环境要求

| 项目 | 要求 |
|---|---|
| MT5 终端 | Windows 7 及以上，已登录任一账户（建议先用模拟盘） |
| 代理（EXE 版） | Windows 10/11 x64，无需安装任何运行库 |
| 代理（Docker 版） | Docker 20+ 与 Docker Compose v2（飞牛 NAS、群晖、Linux 服务器均可） |
| LLM 密钥 | DeepSeek / OpenAI / 其他 OpenAI 兼容服务的 API Key |
| 网络 | EA 与代理之间能互通 8066 端口；代理能访问 LLM 服务 |

## 3. 安装 —— EXE 版（Windows）

**第 1 步：解压**

将 `mt5-2pa-agent-v0.4.4-20260911-1145-win64.zip` 解压到任意目录（建议路径不含中文和空格，如 `D:\mt5-2pa-agent`）。解压后内容：

```
mt5-2pa-agent-v0.4.4-20260911-1145-win64\
├── mt5-2pa-agent.exe      主程序
├── 启动服务.bat            一键启动脚本
├── .env.example           配置模板（首次使用复制为 .env）
├── prompt_engineering\    AI 策略提示词（必须保留）
├── experience\            交易经验库（必须保留）
├── config\                配置目录
├── mql5\PABridge.mq5      MT5 端 EA 源码
└── docs\用户手册.md        本手册
```

**第 2 步：配置 LLM 密钥**

把 `.env.example` 复制一份并重命名为 `.env`，用记事本打开，至少填写：

```
LLM_API_KEY=sk-你的密钥
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash
```

> 也可以跳过此步，首次启动时在 Web 控制台的配置向导里填写（自动保存到 .env）。

**第 3 步：启动**

双击 `启动服务.bat`，看到服务启动信息后，浏览器打开 `http://127.0.0.1:8066`。

**第 4 步：安装 PABridge EA**（见第 5 节）

## 4. 安装 —— Docker 版（NAS / 服务器）

详细步骤见包内 `docs/DOCKER部署指南.md`，核心流程：

```bash
# 1. 解压源码包并进入目录
tar xzf mt5-2pa-agent-v0.4.4-20260911-1145-docker.tar.gz
cd mt5-2pa-agent

# 2. 生成配置（务必修改桥接令牌为强随机值）
cp .env.example .env
chmod 600 .env
vi .env    # 填写 LLM_API_KEY，设置强随机的 MT5_BRIDGE_TOKEN

# 3. 构建并启动（首次构建约 10~40 分钟）
docker compose up -d --build

# 4. 验证
curl http://127.0.0.1:8066/        # 返回页面即成功
docker compose logs -f             # 查看运行日志
```

**Docker 版注意两点：**

1. 监听地址是 `0.0.0.0:8066`（EA 从外部访问）。若在公网服务器部署，务必设置强随机的 `MT5_BRIDGE_TOKEN`，并用防火墙/安全组限制 8066 端口的来源 IP。
2. EA 里的 `BridgeUrl` 要填**代理机器的 IP**（如 `http://192.168.1.100:8066/bridge/sync`），不能填 127.0.0.1（除非 EA 与容器在同一台机器）。

## 5. PABridge EA 安装与配置（MT5 端）

1. 打开 MT5 → 文件 → 打开数据文件夹 → `MQL5\Experts\`，把 `mql5\PABridge.mq5` 复制进去。
2. 在 MetaEditor 中打开该文件，按 **F7 编译**（应显示 0 errors）。
3. MT5 → 工具 → 选项 → **EA 交易** → 勾选"允许算法交易"，并在 **WebRequest 允许的 URL** 中添加：
   - EXE 版：`http://127.0.0.1:8066`
   - Docker 版：`http://代理机器IP:8066`
4. 把任意一张图表（如 XAUUSD M15）上挂载 PABridge EA，按参数表填写，勾选"允许算法交易"后确定。
5. 图表左上角出现桥接状态注释、Web 控制台右上角桥接状态变绿，即部署完成。

**EA 输入参数：**

| 参数 | 说明 | 填写 |
|---|---|---|
| BridgeUrl | 代理的桥接端点 | `http://127.0.0.1:8066/bridge/sync`（EXE 版）或 `http://代理IP:8066/bridge/sync`（Docker 版） |
| BridgeToken | 桥接令牌，须与 `.env` 的 `MT5_BRIDGE_TOKEN` 一致 | 与 .env 相同 |
| MagicNumber | 魔术号，须与 `.env` 的 `MT5_MAGIC_NUMBER` 一致 | `20260907` |
| VerboseLog | 详细日志开关 | 排障时打开，日志见 MT5"专家"标签页 |

> 品种名支持经纪商后缀（如 Exness 的 `XAUUSDm`）：代理端会自动解析匹配 EA 上报的规范品种名，配置里直接填 `XAUUSD` 或 `XAUUSDm` 均可。

## 6. Web 控制台使用

浏览器打开 `http://127.0.0.1:8066`（或 `http://代理IP:8066`）。

| 区域 | 功能 |
|---|---|
| 顶栏 | 桥接连接状态（绿=EA 正常同步）、运行模式（DEMO/LIVE）、涨跌配色切换（红涨绿跌 / 绿涨红跌） |
| K 线图 | 实时行情（数据由 EA 推送），可切换周期 |
| 分析面板 | 手动触发一次 AI 分析，查看两阶段推理结果（市场诊断 + 交易决策） |
| 自动交易 | 开启/关闭自动交易、选择交易系统与品种周期、设置交易时段 |
| 账户 | 余额、净值、持仓与挂单列表；支持手动平仓/撤单（只操作本代理魔术号的单） |
| 历史 | 历史决策记录与交易审计查询 |
| 配置 | 配置向导（保存到 .env） |

**登录与账号权限**：控制台自带账号体系（详见包内 HTML 版手册）。首次启动自动创建管理员 `admin/admin123` 与只读 `viewer/viewer123`（可用 `.env` 的 `WEB_ADMIN_*`/`WEB_VIEWER_*` 覆盖，仅 `config/users.json` 不存在时生效），**默认密码务必登录后立即修改**。只读账号仅可查看，一切写操作（含直接调 API）被服务端 403 拦截；管理员可增删账号、重置密码。

**涨跌配色切换（顶栏）**：顶栏「模拟交易 / 实盘交易」徽标左侧有配色切换按钮，可在**红涨绿跌**（默认，国内习惯）与**绿涨红跌**（国际惯例）之间一键切换。选择保存在浏览器本地（`localStorage` 键 `mt5_updown`），刷新与重登后保持，且只影响当前浏览器，不改变服务端配置。切换会立即作用于 K 线蜡烛、盈亏数值、AI 决策方向（做多 / 做空）、侧栏与历史记录方向、周期涨跌幅、权益曲线浮盈带与悬停气泡，无需刷新页面。两点固定不变：**净值线为蓝色身份色**（不随涨跌配色变化，避免"绿色净值线在红涨绿跌下被误读成下跌"）；**品牌色（主按钮、品牌方块、徽标、开关、焦点框）始终为绿色**，与涨跌语义无关。

**总权益曲线（账户页）**：代理每 60 秒自动采样一次账户状态（总权益/余额/浮动盈亏），按天持久化于 `records/equity/`，重启自动回填。支持快捷时间段（1 时/24 时/7 天/30 天/全部）与自定义起止查询；曲线按时间比例绘制，长区间自动降采样（服务端最多返回 160 点）。曲线为**双线**：净值（蓝色实线，随时间连续变化）与余额（灰色阶梯线，仅在平仓/出入金时跳变），两线之间填充的色带即**浮动盈亏**——持仓期间两线张开，平仓瞬间余额跳一级、两线重新贴合，可直观看出浮盈贡献了多少、哪次平仓落袋多少。鼠标悬停可看到该时刻的净值 / 余额 / 浮盈气泡。**收益率百分比以所选区间第一个采样点的权益为基准**（区间起点=0%）：标题栏显示区间总收益率，右侧金额刻度下方同步标注百分比，图中虚线为 0% 基准线；切换时间段时基准随之移动，不同区间的收益率不可直接横向比较。数据从代理运行时开始积累，历史不可回补；EA 未连接期间不采样。

**开启自动交易的安全确认**：首次在实盘账户开启时，控制台会要求确认；`.env` 中 `MT5_LIVE_TRADING_ACKNOWLEDGED=true` 表示已知悉实盘风险。

## 7. 三套交易系统

在自动交易设置或 `.env` 的 `TRADING_SYSTEM` 中选择：

| 系统 | 说明 |
|---|---|
| `2pa` | Al Brooks 价格行为学：八态市场周期 + 二元决策树（默认） |
| `dog_walking` | "遛狗"均线回归：SMA14/170 通道 |
| `adaptive` | 双引擎自适应：自动在 2pa 与遛狗之间切换 |

## 8. 配置参考（.env）

**LLM 相关**

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `LLM_API_KEY` | 空 | LLM 服务 API 密钥（必填） |
| `LLM_BASE_URL` | `https://api.deepseek.com` | OpenAI 兼容接口地址 |
| `LLM_MODEL` | `deepseek-v4-flash` | 模型名 |
| `LLM_THINKING` | `false` | 是否启用思考模式 |
| `LLM_STAGE_TIMEOUT_SECONDS` | `240` | 单阶段推理超时（秒） |

**桥接与交易**

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `MT5_BRIDGE_TOKEN` | 空 | 桥接令牌，与 EA 的 BridgeToken 一致；Docker/公网部署务必设置强随机值 |
| `MT5_MAGIC_NUMBER` | `20260907` | 魔术号，须与 EA 一致；代理只管理自己魔术号的单 |
| `MT5_AUTO_TRADING_ENABLED` | `false` | 自动交易总开关 |
| `MT5_DEFAULT_ORDER_SIZE` | `0.1` | 默认手数 |
| `MT5_AUTO_ORDER_SIZING` | `true` | 动态算量（按风险百分比自动计算手数） |
| `MT5_RISK_PERCENT` | `2` | 单笔风险占净值百分比 |
| `MT5_MAX_MARGIN_PERCENT` | `25` | 单笔保证金占用上限 |
| `MT5_BLOCK_NEW_ENTRIES_WHEN_POSITION_OPEN` | `true` | 持仓互斥：有持仓时禁止同向加仓 |
| `MT5_MAX_PENDING_BARS` | `3` | 信号最大容许滞留 K 线数（超龄信号不下单） |
| `MT5_AUTOMATION_POLL_SECONDS` | `20` | 自动交易轮询间隔 |
| `MT5_AUTOMATION_SESSION_PRESET` | `always` | 交易时段预设：always / 美盘 / 伦敦 / 亚盘 / custom |

修改 `.env` 后需重启服务（EXE：关掉窗口重新运行 bat；Docker：`docker compose restart`）。

## 9. 日志与审计

**代理端日志**（EXE 版为控制台窗口；Docker 版 `docker compose logs -f`）：

- `[决策执行] AI 决策推送下单: ...` — AI 决策的完整下单参数（标的/类型/方向/手数/价格/SL/TP）
- `[决策执行] Cancel-Replace 撤销旧挂单: #票据 ...` — 新单前自动撤旧挂单
- `[桥接] 指令已入队待 EA 领取 / EA 本次同步领取 N 条指令` — 指令下发过程
- `[桥接] EA 执行成功/失败: id=... 回执=票据` — EA 执行结果
- 审计文件 `records/trade_audit.jsonl` — 每笔交易决策的完整 JSON 审计记录

**EA 端日志**：MT5"工具箱 → 专家"标签页；打开 EA 参数 `VerboseLog=true` 可看执行细节（指令接收、下单 retcode 等）。

## 10. 常见问题（FAQ）

**Q1：桥接状态一直显示未连接？**
依次检查：① EA 是否已挂载到图表并允许算法交易；② WebRequest 白名单是否已添加代理地址（注意不带 `/bridge/sync` 路径）；③ `BridgeUrl`/`BridgeToken` 是否与代理配置一致；④ EA 与代理网络是否互通（Docker 版用 `telnet 代理IP 8066` 测试）。

**Q2：提示"等待 MT5 推送 XX K 线超时"？**
该品种/周期在当前账户不可用，或 EA 尚未完成首次订阅（约几秒）。若持续超时，打开 EA 的 `VerboseLog` 查看 CopyRates 是否失败。

**Q3：交易记录显示"MT5 执行失败"？**
看代理日志中 `[桥接] EA 执行失败` 一行的具体原因，以及 EA 端"专家"日志里的 retcode（如 10015 无效价格、10019 无足够资金）。

**Q4：AI 决策了限价单但长期不成交？**
挂单为 GTC（直到取消）型。正常情况下，后续新决策会自动撤旧挂新（Cancel-Replace）；若 AI 转为观望，旧挂单会保留，可在控制台"账户"页手动撤单（只撤本代理魔术号的单，不影响手工单）。

**Q5：Exness 之类后缀品种怎么填？**
直接填基础名（如 `XAUUSD`）即可，代理会自动匹配 EA 上报的规范名（`XAUUSDm`）；填规范名也可以。

**Q6：如何从模拟盘切到实盘？**
EA 随 MT5 账户自动识别，无需改配置；实盘首次开启自动交易需在控制台确认，且 `.env` 设 `MT5_LIVE_TRADING_ACKNOWLEDGED=true`。

**Q7：端口想改？**
EXE 版编辑 `启动服务.bat` 中的 `--port` 参数；Docker 版修改 `docker-compose.yml` 的端口映射。改端口后记得同步更新 WebRequest 白名单和 EA 的 BridgeUrl。

## 11. 安全与风险提示

- **先用模拟盘**：请务必在模拟账户上完整验证策略与配置后，再考虑接入实盘。
- **AI 决策不构成投资建议**：大模型输出具有不确定性，自动交易存在亏损风险，请自行承担投资决策责任。
- **令牌保护**：`MT5_BRIDGE_TOKEN` 是桥接的唯一凭证，切勿泄露；公网部署必须配置强随机令牌并限制来源 IP。
- **密钥安全**：`.env` 含 API 密钥，请妥善保管文件权限（Docker 版已设 600）。
- **最小权限**：代理只操作与自己魔术号匹配的持仓/挂单，不会触碰你在 MT5 中手工下的单。
