MT5 2PA Agent · v0.4.4

MT5 2PA Agent 用户手册

AI 价格行为交易代理（MetaTrader 5 桥接版）· 适用 EXE 版（Windows） 与 Docker 版（Linux / NAS）

本手册随发行包附带，如有更新以最新包内版本为准。

一句话概括：MT5 2PA Agent 自动拉取 MT5 行情 → 计算 EMA/ATR/SMA 指标与 K 线几何特征 → 两阶段调用大模型（市场诊断 + 交易决策）→ 风控校验后，通过 PABridge EA 在 MT5 中自动下单，并提供 Web 控制台实时查看与管理。

1. 系统组成

系统由两部分组成，二者通过 HTTP 通信：

  • MT5 终端 + PABridge EA：必须运行在 Windows（MT5 无法装入 Docker），负责行情上报与实际下单。
  • 2PA Agent 代理：核心程序，EXE 版跑在 Windows，Docker 版可跑在 NAS / 服务器；提供 Web 控制台（默认端口 8066）。
  • LLM 大模型：需要一个 OpenAI 兼容接口的 API Key（默认 DeepSeek）。
EXE 版与 Docker 版功能完全相同，二选一即可。代理与 MT5 可以在同一台电脑，也可以分属两台机器（同一局域网 / 跨机器需网络互通）。

2. 环境要求

项目要求
MT5 终端Windows 7 及以上，已登录任一账户（建议先用模拟盘）
代理（EXE 版）Windows 10/11 x64，无需安装任何运行库，解压即用
代理（Docker 版）Docker 20+ 与 Docker Compose v2（飞牛 NAS、群晖、Linux 服务器均可）
LLM 密钥DeepSeek / OpenAI / 其他 OpenAI 兼容服务的 API Key
网络EA 与代理之间能互通 8066 端口；代理能访问 LLM 服务

3. 安装 —— EXE 版（Windows）

推荐新手无需编译

第 1 步：解压

将 mt5-2pa-agent-v0.4.4-20260911-1145-win64.zip 解压到任意目录（建议路径不含中文和空格，如 D:\mt5-2pa-agent）。解压后目录结构：

mt5-2pa-agent-v0.4.4-20260911-1145-win64\
├── mt5-2pa-agent.exe       主程序（已编译，双击即运行）
├── 启动服务.bat            一键启动脚本
├── 免费AI注册.txt          LLM 密钥获取指引
├── .env.example           配置模板（首次使用复制为 .env）
├── config\                配置目录（settings.example.json）
├── mql5\PABridge.ex5      MT5 端 EA（已编译，直接放进 MT5）
├── experience\            交易经验库（必须保留）
├── prompt_engineering\    AI 策略提示词（必须保留）
└── docs\用户手册.html      本手册（及 用户手册.md）

第 2 步：配置 LLM 密钥

把 .env.example 复制一份并重命名为 .env，用记事本打开，至少填写：

LLM_API_KEY=sk-你的密钥
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-v4-flash
也可以跳过此步，首次启动后在 Web 控制台的配置向导里填写（自动保存进 .env 并热加载）。详见 第 6 节。

第 3 步：启动

双击 启动服务.bat，看到服务启动信息后，浏览器打开 http://127.0.0.1:8066。

第 4 步：安装 PABridge EA

见 第 5 节。EA 连通后，控制台右上角桥接状态变绿即部署完成。

4. 安装 —— Docker 版（NAS / 服务器）

适合 7×24首次构建 10~40 分钟

本版发行包内含完整源码，由 Docker 在容器内完成 Rust 编译。核心流程（详细步骤见包内 docs/DOCKER部署指南.md）：

# 1. 解压源码包并进入目录
tar xzf mt5-2pa-agent-v0.4.4-20260911-1145-docker.tar.gz
cd mt5-2pa-agent

# 2. 生成配置（务必修改桥接令牌为强随机值）
cp .env.example .env
chmod 600 .env
vi .env    # 填写 LLM_API_KEY，设置强随机的 MT5_BRIDGE_TOKEN

# 3. 构建并启动（首次构建约 10~40 分钟）
docker compose up -d --build

# 4. 验证
curl http://127.0.0.1:8066/        # 返回页面即成功
docker compose logs -f             # 查看运行日志
Docker 版两点注意：
  1. 监听地址是 0.0.0.0:8066（EA 从外部访问）。若在公网服务器部署，务必设置强随机的 MT5_BRIDGE_TOKEN，并用防火墙 / 安全组限制 8066 端口的来源 IP。
  2. EA 里的 BridgeUrl 要填代理机器的 IP（如 http://192.168.1.100:8066/bridge/sync），不能填 127.0.0.1（除非 EA 与容器在同一台机器）。

5. PABridge EA 安装与配置（MT5 端）

发行包提供的是已编译好的 PABridge.ex5，无需在 MetaEditor 中编译，直接放入 MT5 即可使用。
  1. 放入 EA 文件：MT5 → 文件 → 打开数据文件夹 → 进入 MQL5\Experts\，把发行包里的 mql5\PABridge.ex5 复制进去。
  2. 允许 WebRequest（必做）：MT5 → 工具 → 选项 → EA 交易 → 勾选"允许算法交易"，并在 WebRequest 允许的 URL 中添加：
    • EXE 版（同机）：http://127.0.0.1:8066
    • Docker 版（跨机）：http://代理机器IP:8066
    注意：添加的 URL 不带 /bridge/sync 路径，只需到端口即可。
  3. 挂载 EA：把"导航器 → 智能交易系统"里的 PABridge 拖到任意一张图表（如 XAUUSD M15），在"输入"标签页按参数表填写，勾选"允许算法交易"后确定。
  4. 确认连通：图表左上角出现桥接状态注释、Web 控制台右上角桥接状态变绿，即部署完成。

6. Web 控制台使用

浏览器打开 http://127.0.0.1:8066（或 http://代理IP:8066）。

区域功能
顶栏桥接连接状态（绿=EA 正常同步）、运行模式（DEMO / LIVE，由 MT5 账户类型自动识别）
K 线图实时行情（数据由 EA 推送），可切换周期、双系统均线叠加
分析面板手动触发一次 AI 分析，查看两阶段推理结果（市场诊断 + 交易决策）
自动交易开启 / 关闭自动交易、选择交易系统与品种周期、设置交易时段
账户余额、净值、持仓与挂单列表；支持手动平仓 / 撤单（只操作本代理魔术号的单）
历史历史决策记录与交易审计查询
配置配置向导（保存到 .env 并热加载）

登录与账号权限

控制台自带账号体系，打开页面需先登录：

  • 首次启动自动创建两个内置账号：管理员 admin / admin123 与只读 viewer / viewer123（可用 .env 的 WEB_ADMIN_USERNAME / WEB_ADMIN_PASSWORD / WEB_VIEWER_USERNAME / WEB_VIEWER_PASSWORD 覆盖，仅在账号文件 config/users.json 不存在时生效）。默认密码务必登录后立即修改！
  • 管理员：全部权限（运行 AI 分析、自动交易、系统配置、撤单、删除记录、用户管理）。
  • 只读账号：仅可查看行情、账户、决策与交易历史；所有写操作（含绕过界面直接调用 API）都会被服务端拦截并返回 403，防止"界面隐藏但接口裸奔"的漏洞。
  • 用户管理：管理员在顶栏「👥 用户管理」中添加 / 删除账号、重置密码、修改自己的密码（系统至少保留一个管理员，不能删除当前登录账号）。
  • 安全机制：口令以「盐 + 1 万轮 SHA-256」哈希存于 config/users.json（不存明文）；会话为 12 小时 HttpOnly Cookie；同一账号连续失败 5 次锁定 5 分钟；删除用户 / 修改密码会立即吊销其全部登录会话。

涨跌配色切换（顶栏）

顶栏「模拟交易 / 实盘交易」徽标左侧有一个配色切换按钮，可在 红涨绿跌（默认，国内习惯）与 绿涨红跌（国际惯例）之间一键切换：

  • 选择保存在浏览器本地（localStorage 键 mt5_updown），刷新 / 重新登录后保持；只影响当前浏览器，不改变服务端配置。
  • 切换立即作用于：K 线蜡烛、盈亏数值、AI 决策方向（做多 / 做空）、侧栏与历史记录方向、周期涨跌幅、权益曲线浮盈带与悬停气泡。
  • 净值线保持蓝色身份色，不随涨跌配色变化——避免"绿色净值线在红涨绿跌下被误读成下跌"。
  • 品牌色固定不变：主按钮、品牌方块、徽标、开关、输入框焦点环始终为绿色，与涨跌语义无关。

总权益曲线（账户页）

「账户」页的总权益曲线记录账户净值随时间的变化：代理每 60 秒自动采样一次（总权益 / 余额 / 浮动盈亏），按天持久化保存于 records/equity/ 目录，重启后自动回填，曲线支持：

  • 快捷时间段：1 时 / 24 时 / 7 天 / 30 天 / 全部；
  • 自定义起止：用日期时间控件选择任意起止时刻后点「查询」；
  • 曲线按时间比例绘制，长区间自动降采样（服务端最多返回 160 点），停机 / 断线时段曲线自然断开。
  • 双线含义：净值（蓝色实线，随持仓盈亏连续变化）与余额（灰色阶梯线，仅在平仓 / 出入金时跳变），两线之间填充的色带就是浮动盈亏——持仓期间两线张开，平仓瞬间余额跳一级、两线重新贴合。鼠标悬停可查看该时刻的净值 / 余额 / 浮盈气泡。
  • 收益率百分比：以所选区间第一个采样点的权益为基准（即区间起点为 0%），标题栏显示该区间总收益率，右侧金额刻度下方同步标注对应的百分比；图中虚线即 0% 基准线。切换时间段时 0% 会跟着移动，因此不同区间的收益率不可直接横向比较。
注意：曲线数据从代理部署运行时开始积累，之前的历史无法回补；EA 未连接期间不采样。

开启自动交易的安全确认

首次在实盘账户开启时，控制台会要求确认：模拟账户输入 ENABLE DEMO、实盘账户输入 ENABLE LIVE。.env 中 MT5_LIVE_TRADING_ACKNOWLEDGED=true 表示已知悉实盘风险。

建议流程：先在 Web 控制台手动点几次"分析"，确认 LLM 能正常返回、风控校验通过，并在模拟账户上跑几天观察，再考虑接入实盘。

  • [决策执行] AI 决策推送下单: ... — AI 决策的完整下单参数（标的 / 类型 / 方向 / 手数 / 价格 / SL / TP）
  • [决策执行] Cancel-Replace 撤销旧挂单: #票据 ... — 新单前自动撤旧挂单
  • [桥接] 指令已入队待 EA 领取 / EA 本次同步领取 N 条指令 — 指令下发过程
  • [桥接] EA 执行成功 / 失败: id=... 回执=票据 — EA 执行结果
  • 审计文件 records/trade_audit.jsonl — 每笔交易决策的完整 JSON 审计记录

EA 端日志：MT5"工具箱 → 专家"标签页；打开 EA 参数 VerboseLog=true 可看执行细节（指令接收、下单 retcode 等）。

10. 常见问题（FAQ）

Q1：桥接状态一直显示未连接？

依次检查：① EA 是否已挂载到图表并允许算法交易；② WebRequest 白名单是否已添加代理地址（注意不带 /bridge/sync 路径）；③ BridgeUrl / BridgeToken 是否与代理配置一致；④ EA 与代理网络是否互通（Docker 版用 telnet 代理IP 8066 测试）。

Q2：提示"等待 MT5 推送 XX K 线超时"？

该品种 / 周期在当前账户不可用，或 EA 尚未完成首次订阅（约几秒）。若持续超时，打开 EA 的 VerboseLog 查看 CopyRates 是否失败。

Q3：交易记录显示"MT5 执行失败"？

看代理日志中 [桥接] EA 执行失败 一行的具体原因，以及 EA 端"专家"日志里的 retcode（如 10015 无效价格、10019 无足够资金）。

Q4：AI 决策了限价单但长期不成交？

挂单为 GTC（直到取消）型。正常情况下，后续新决策会自动撤旧挂新（Cancel-Replace）；若 AI 转为观望，旧挂单会保留，可在控制台"账户"页手动撤单（只撤本代理魔术号的单，不影响手工单）。

Q5：Exness 之类后缀品种怎么填？

直接填基础名（如 XAUUSD）即可，代理会自动匹配 EA 上报的规范名（XAUUSDm）；填规范名也可以。

Q6：如何从模拟盘切到实盘？

EA 随 MT5 账户自动识别，无需改配置；实盘首次开启自动交易需在控制台确认，且 .env 设 MT5_LIVE_TRADING_ACKNOWLEDGED=true。

Q7：端口想改？

EXE 版编辑 启动服务.bat 中的 --port 参数；Docker 版修改 docker-compose.yml 的端口映射。改端口后记得同步更新 WebRequest 白名单和 EA 的 BridgeUrl。

Q8：EA 放进去后 MT5 里看不到 / 无法挂载？

确认 PABridge.ex5 放在 MQL5\Experts\ 目录下（不是 Indicators 或 Scripts）。放入后需在"导航器"面板右键"刷新"，或在"文件 → 打开数据文件夹"确认路径正确。

11. 安全与风险提示

  • 先用模拟盘：请务必在模拟账户上完整验证策略与配置后，再考虑接入实盘。
  • AI 决策不构成投资建议：大模型输出具有不确定性，自动交易存在亏损风险，请自行承担投资决策责任。
  • 令牌保护：MT5_BRIDGE_TOKEN 是桥接的唯一凭证，切勿泄露；公网部署必须配置强随机令牌并限制来源 IP。
  • 密钥安全：.env 含 API 密钥，请妥善保管文件权限（Docker 版已设 600）。
  • 最小权限：代理只操作与自己魔术号匹配的持仓 / 挂单，不会触碰你在 MT5 中手工下的单。
